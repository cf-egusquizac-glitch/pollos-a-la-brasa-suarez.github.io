## 📋 Descripción

Pollos a la Brasa Suárez es una aplicación web moderna y responsive diseñada para un restaurante especializado en pollos a la brasa. La aplicación permite a los usuarios explorar el menú, conocer la historia del restaurante, realizar pedidos y gestionar su cuenta de usuario.

## ✨ Características

- 🎨 **Diseño Responsive**: Se adapta perfectamente a dispositivos móviles, tablets y desktop
- 🍗 **Menú Digital**: Catálogo completo de productos con imágenes y precios
- 📱 **Navegación Intuitiva**: Menú hamburguesa para móviles y navegación superior para desktop
- 👤 **Sistema de Autenticación**: Login y registro de usuarios
- 📊 **Dashboard de Usuario**: Visualización de pedidos y estadísticas
- 📍 **Mapa de Ubicación**: Integración con Google Maps
- 📧 **Formulario de Contacto**: Para consultas y pedidos especiales
- 🎯 **Logo Animado**: Ícono rotativo en header y footer

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Estilos modernos con CSS Grid y Flexbox
- **JavaScript**: Interactividad y navegación
- **Font Awesome**: Iconos profesionales
- **Google Fonts**: Tipografías Pacifico y Roboto
